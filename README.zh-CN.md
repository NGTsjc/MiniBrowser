# MiniBrowser

[English](README.md) | **简体中文**

一个轻巧的便携网页小窗，让常用网页随手可见。无论是仪表盘、视频还是参考资料，都可以放进适合桌面布局的小窗口。

## 功能特点

- **自在调整：**自由缩放、置顶，支持不透明度、窗口圆角、主题色和四角拖动区位置设置。
- **一次性浏览：**浏览期间保留登录状态，关闭或重启后开启全新会话。
- **随时收起：**通过托盘或自定义快捷键显隐，默认隐藏时暂停媒体。
- **简单浏览：**新页面链接在当前窗口打开，支持 Ctrl＋滚轮缩放网页。
- **便携使用：**无需安装应用，设置与临时浏览数据存放在 EXE 同级目录。
- **自定义文案：**在设置中选择语言 JSON，确认后立即切换；附带完整中文示例。

## 开始使用

需要 **Windows 10/11 x64**，并已安装 **Microsoft Edge WebView2 Runtime**。

1. 从 [Releases](https://github.com/NGTsjc/MiniBrowser/releases) 下载便携包，解压到可写文件夹。
2. 双击运行 `MiniBrowser.exe`。
3. 右键引导页或窗口角落的拖动区，选择 **Settings（设置）**，输入网页地址。

按住拖动区移动窗口，拖动边缘调整大小。托盘菜单提供显示、隐藏、重置窗口、重启和关闭；默认不显示任务栏按钮。

切换中文：将 `locale.example.json` 复制到 `MiniBrowser.data`，在 **Settings → Language file** 中选择该文件并确认。清空该字段后确认可恢复英文。

## 设置与隐私

设置保存在 EXE 同级的 `MiniBrowser.data` 中。移动程序时一并带上该文件夹，即可保留偏好。

隐藏窗口会保留当前会话。“清空会话”会移除 Cookie 和网站存储并重新加载网页；关闭会丢弃会话，仍被占用的文件会在后续启动时补清理。这不包含 Windows 或 WebView2 自身维护的记录。

目前仅运行一个浏览窗口，暂不支持下载、摄像头、麦克风、定位和独立登录弹窗；尚未支持 macOS。
